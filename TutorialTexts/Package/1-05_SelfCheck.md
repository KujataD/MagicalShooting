# 【1-05】提出前に自分で動作確認しよう【1章：パッケージ編】

1. クリア条件：空のプロジェクトに読み込んで、動くか確認できればOK！

2. 書き出したパッケージ、そのまま提出したくなりますが、あと1ステップだけ待ってください。
   **自分のプロジェクトでは動くのに、統合先では動かない**というのが、パッケージで一番多いトラブルです。

3. 理由は1-03で説明した通りです。パッケージには入らないものがあるからです。

   - Package Managerで追加した機能
   - タグ、レイヤー、入力設定

   自分のプロジェクトにはこれらが全部そろっているので、当然動きます。でも統合先は別のプロジェクトです。

4. そこで、**空のプロジェクトを作って、自分のパッケージだけを読み込んでみます**。
   ここで動けば、統合先でもほぼ確実に動きます。動かなければ、統合前に自分で直せます。

5. UnityHubで「New project」を押して、新しいプロジェクトを作りましょう。

   - テンプレート：**自分のミニゲームと同じもの**（2Dで作ったなら Universal 2D）
   - Unityバージョン：**チームで決めたバージョン**（今回は 6000.3.15f1）
   - プロジェクト名：`ImportTest` など、分かるもの

   ※バージョンが違うと、それだけで動かないことがあります。ここは必ずそろえてください。

6. 新しいプロジェクトが開いたら、`Assets > Import Package > Custom Package...` を選び、書き出したパッケージを読み込みます。
   （詳しい手順は次回1-06で説明します。ここでは読み込んで動かすだけです）

7. 読み込んだら、この4つを確認してください。

   | 確認項目 | 見るところ |
   |---|---|
   | エラーが出ていないか | Consoleに赤いエラーが無いか |
   | シーンが開けるか | 自分のシーンをダブルクリックして開く |
   | 見た目が崩れていないか | 白い四角（Missing）になっている絵が無いか |
   | 実際に遊べるか | Playボタンを押して動かしてみる |

8. 【よくあるエラー1】赤いエラーで「型または名前空間が見つかりません」

   実際にやってみたところ、こういうエラーが出ました。

   ![読み込み後に出たエラー](../package_images/1-06_error_detail.png)

   これは、スクリプトの先頭にある `using` が、統合先に無い機能を指しているときに出ます。

   ```csharp
   using Unity.VisualScripting;   // ← この機能が統合先に無い
   using Unity.Mathematics;       // ← これも
   ```

   対処は2つあります。

   - **その機能を実際に使っていない場合**：`using` の行を消す（多くの場合こちらです。エディタが自動で追加しただけ）
   - **実際に使っている場合**：1-03で説明した通り、「この機能を使っています」と統合担当に申告する

9. 【よくあるエラー2】絵が白い四角になる

   1-05でも触れた.metaの問題か、書き出しのときに「Include dependencies」のチェックが外れていた可能性があります。
   もう一度1-04の手順で、チェックを入れて書き出し直してください。

10. 【よくあるエラー3】タグ関連のエラーで止まる

    `Tag: ○○ is not defined` のようなエラーが出たら、自分で追加したタグを使っています。
    統合先に同じタグを追加してもらう必要があるので、**タグ名を必ず申告してください**。

11. 空のプロジェクトで問題なく動いたら、いよいよ提出です。
    決められた名前のファイルと一緒に、1-03でまとめた情報を書いて提出しましょう。

    ```
    【提出】GameJam_2026_07_TeamAlpha_MazeRunner.unitypackage

    ・最初に開くシーン：Title_TeamAlpha.unity
    ・追加した機能：TextMeshPro
    ・追加したタグ：Item、Goal
    ・追加したレイヤー：なし
    ・操作方法：矢印キーで移動、スペースでジャンプ
    ```

12. 空のプロジェクトで動作確認ができて、提出できたら、今回は完成です！
    ここまでで、書き出す側の作業は終わりです。次回は受け取る側（統合担当）の作業を見ていきます。
