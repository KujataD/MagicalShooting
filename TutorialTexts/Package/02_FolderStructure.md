# 【2】自分のフォルダにまとめる

1. 書き出しの前に、ファイルの置き場所を整理します。ここをやらないと、統合するときに全チームのファイルが混ざります。

2. よくない例から見てみます。作りながら進めると、だいたいAssetsフォルダはこうなっています。

   ```
   Assets/
     ├ Scenes/
     ├ Scripts/
     ├ Images/
     ├ Prefabs/
     └ Audio/
   ```

   一見きれいですが、**このまま書き出すと問題が起きます**。統合プロジェクトに全チーム分を読み込むと、こうなるからです。

   ```
   Assets/
     ├ Scenes/     ← 全チームのシーンが1か所に集まる
     ├ Scripts/    ← 全チームのスクリプトが混ざる
     ├ Images/     ← 全チームの画像が混ざる
     └ ...
   ```

   どれが誰のファイルか分からなくなりますし、**同じ名前のファイルがあると上書きされます**。`Player.cs` や `Title.unity` のような名前は、まず間違いなくかぶります。

3. そこで、**自分のミニゲーム専用のフォルダを1つ作って、その中に全部入れます**。

   ```
   Assets/
     └ GameJam_2026_07_TeamA_MazeRunner/
         ├ Scenes/
         ├ Scripts/
         ├ Images/
         ├ Prefabs/
         └ Audio/
   ```

   こうしておけば、統合プロジェクトに読み込んでも、チームごとにきれいに分かれます。

   ```
   Assets/
     ├ GameJam_2026_07_TeamA_MazeRunner/
     ├ GameJam_2026_07_TeamB_ShootingStar/
     └ GameJam_2026_07_TeamC_RhythmCat/
   ```

4. フォルダ名は、提出ファイルと同じ名前にします。

   ```
   GameJam_<開始年yyyy>_<開始月mm>_Team<チーム名>_<ゲームタイトル>
   ```

   ファイル名とフォルダ名がそろっていると、迷とら運営が「このフォルダはどのチームのものか」を確認せずに済みます。

5. では作ります。UnityのProjectウィンドウで、Assetsフォルダを右クリック →「Create」→「Folder」。
   名前を上の形式（例：`GameJam_2026_07_TeamA_MazeRunner`）にします。

6. 次に、既存のフォルダをこの中へ移動します。

   ![Projectウィンドウでフォルダをまとめた状態](../package_images/1-02_project_structure.png)

   **必ずUnityのProjectウィンドウ上でドラッグして移動してください。**
   エクスプローラー（Finder）で直接動かすと、Unityが参照を追えなくなって、シーンからスクリプトや画像が外れることがあります。

   用語：.metaファイル
   Unityが自動で作る、素材とセットの設定ファイル。**Unity上で移動すれば.metaも一緒に動く**ので参照は壊れませんが、エクスプローラーで動かすと.metaだけ取り残されて壊れる場合があります。フォルダの整理はUnity上で、が鉄則です。

7. 移動が終わったら、Unityを再生（Play）して、ゲームがちゃんと動くか確認します。
   ここで動かなくなっていたら、参照が外れている可能性があります。**書き出す前に必ず直してください**。

8. この時点でよくあるトラブルはこの3つです。

   | 症状 | 原因と対処 |
   |---|---|
   | シーンを開いたらオブジェクトが白い四角になった | 画像の参照が外れている。Inspectorで画像を割り当て直す |
   | Missing (Mono Script) と表示される | スクリプトの参照が外れている。Inspectorでスクリプトを割り当て直す |
   | Consoleに赤いエラーが出る | エラー内容を読んで対処。まず移動前の状態に戻せないか確認 |
