# 【1】提出するもの

1. ミニゲームは、チームごとに別々のUnityプロジェクトで作られています。これを1つのプロジェクトにまとめるには、プロジェクトを丸ごと渡すのではなく、**そのミニゲームを動かすのに必要なファイル一式**を取り出して渡す必要があります。

2. そのための仕組みが、Unityに用意されている Unity Package です。

   用語：Unity Package（.unitypackage）
   Unityのプロジェクトから、**指定したファイルをまとめて1つのファイルに書き出したもの**。受け取った側は、それを自分のプロジェクトに読み込むと、フォルダ構成そのままでファイルが追加されます。

3. 提出するものは2つです。

   | 提出物 | 中身 |
   |---|---|
   | **.unitypackage ファイル** | ミニゲームのファイル一式 |
   | **ReadMe.md** | ゲームの説明書（操作方法、追加した機能など） |

   ※ReadMe.mdは、パッケージの中に含める形で提出します（作り方は【3】）。

4. 作業の流れはこうなります。

   ```
   ① 自分のミニゲーム用フォルダにファイルをまとめる　【2】
              ↓
   ② ReadMe.md を書いて、そのフォルダに置く　【3】
              ↓
   ③ .unitypackage に書き出す　【4】
              ↓
   ④ 空のプロジェクトで動作確認して提出　【5】
              ↓
   ⑤ 迷とら運営が統合プロジェクトに読み込む　【6】
   ```

5. 【最重要】提出するファイルの名前は、全チーム統一します。

   ```
   GameJam_<開始年yyyy>_<開始月mm>_Team<チーム名>_<ゲームタイトル>
   ```

   例：

   ```
   GameJam_2026_07_TeamA_MazeRunner.unitypackage
   GameJam_2026_07_TeamB_ShootingStar.unitypackage
   GameJam_2026_07_TeamC_RhythmCat.unitypackage
   ```

   - `<>` は書きません。`Team` の後にそのままチーム名（A、B、C…）をつなげます
   - 開始年月は、ゲームジャムが始まった年と月を2桁で書きます（2026年7月なら `2026_07`）
   - **半角英数とアンダースコア（_）だけ**を使います。日本語やスペースは、読み込む側で不具合の原因になります

6. なぜ名前を統一するのか。迷とら運営の画面には、全チームのファイルが並びます。

   ```
   ⭕ 統一されている場合
      GameJam_2026_07_TeamA_MazeRunner.unitypackage
      GameJam_2026_07_TeamB_ShootingStar.unitypackage
      GameJam_2026_07_TeamC_RhythmCat.unitypackage
      → どれが誰のもので、いつの提出物か一目で分かる

   ✕ バラバラの場合
      game.unitypackage
      最新版.unitypackage
      test2.unitypackage
      → 中身を開くまで分からない。同名ファイルで上書き事故も起きる
   ```
