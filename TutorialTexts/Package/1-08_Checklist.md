## 【A】提出までの流れ

```
① Unityで自分のミニゲーム用フォルダを1つ作る
   名前：GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
        ↓
② そのフォルダの中に、自分の素材・スクリプト・シーンを全部移動
   （移動はUnityのProjectウィンドウ上で！）
        ↓
③ Unityで再生して、まだ動くか確認
        ↓
④ 追加した機能・タグ・レイヤーを確認してメモ（1-03）
        ↓
⑤ ReadMe.md を書いて、自分のフォルダの中に置く（1-06）
        ↓
⑥ フォルダを右クリック →「Export As Asset Package...」
        ↓
⑦ Include dependencies にチェックが入っているか確認 → Export
        ↓
⑧ ファイル名を決められた形式で保存
        ↓
⑨ 空のプロジェクトを作って読み込み、動作確認（1-05）
        ↓
⑩ パッケージ＋ReadMe.mdを提出
```

---

## 【B】ファイル名とフォルダ名のルール

```
GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
```

| 良い例 ⭕ | 避けたい例 ✕ |
|---|---|
| GameJam_2026_07_TeamA_MazeRunner | game.unitypackage |
| GameJam_2026_07_TeamB_ShootingStar | 最新版.unitypackage |
| GameJam_2026_07_TeamC_RhythmCat | GameJam 2026 07 チームC.unitypackage |
| GameJam_2026_07_TeamD_PuzzleBox | teamD_final_ver2.unitypackage |

- `<>` は書かない（`Team` の後にそのままチーム名A〜D）
- **半角英数とアンダースコア（_）だけ**を使う
- 日本語・スペース・記号は使わない
- **フォルダ名もファイル名と同じ**にする

## 【C】パッケージに入るもの・入らないもの

| 種類 | 入る？ | 対応 |
|---|---|---|
| 画像・音・スクリプト・シーン・プレハブ | ⭕ | 自分のフォルダにまとめる |
| Package Managerで追加した機能 | ✕ | ReadMe.mdに書く |
| タグ・レイヤー | ✕ | ReadMe.mdに書く |
| 入力設定（Input） | ✕ | ReadMe.mdに書く |
| Build Settingsのシーン一覧 | ✕ | 「最初に開くシーン」をReadMe.mdに書く |

## 【D】ReadMe.md テンプレート（そのままコピーして使えます）

```markdown
# ゲームタイトル

## ゲーム概要
（どんなゲームか2〜3行で。ジャンル、目的、勝敗条件など）

## 操作方法
- 移動：
- 決定：
- その他：

## 最初に開くシーン
（例：Title_TeamA.unity）

## 追加した機能（Package Manager）
- 無ければ「なし」

## 追加したタグ
- 無ければ「なし」

## 追加したレイヤー
- 無ければ「なし」

## その他
- 想定プレイ時間：
- 終了条件：（どうなったらゲームが終わるか）
- 使用素材：（配布サイトの名前とURL。自作なら「自作」）
- 既知の不具合：
- 制作メンバー：
- 連絡先：（DiscordのID）
```

- 保存するときは、ファイル名 `ReadMe.md`、文字コード **UTF-8**
- 置き場所は**自分のミニゲームのフォルダの中**（パッケージに一緒に入ります）
- 「なし」も必ず書く（空欄だと書き忘れと区別がつきません）

## 【E】提出前チェックリスト

- [ ] 自分のミニゲームのファイルが、1つのフォルダにまとまっている
- [ ] フォルダ名が決められた形式になっている
- [ ] フォルダを移動したあと、Unityで再生して動いた
- [ ] ReadMe.md を書いて、フォルダの中に置いた
- [ ] 「Include dependencies」にチェックを入れて書き出した
- [ ] ファイル名が決められた形式になっている
- [ ] ファイルサイズが極端に小さくない（数KBは中身が空の可能性）
- [ ] 空のプロジェクトに読み込んで、エラー無しで動いた
- [ ] パッケージとReadMe.mdの両方を提出した

## 【F】困ったとき逆引き表

| こうなった | こうする |
|---|---|
| **書き出したファイルが数KBしかない** | フォルダを選ばずに書き出した可能性。自分のフォルダを右クリックしてやり直す |
| **読み込んだら絵が白い四角になる** | Include dependencies のチェック漏れ。チェックを入れて書き出し直す |
| **`型または名前空間が見つかりません` エラー** | 統合先に無い機能を使っている。使っていないなら該当の `using` を消す。使っているならReadMe.mdに書く |
| **`Tag: ○○ is not defined` エラー** | 自分で追加したタグを使っている。ReadMe.mdに書いて、統合先にも追加してもらう |
| **Unityを開いたら Enter Safe Mode? が出た** | コンパイルエラーが残っている。Ignoreで開いて、Consoleの赤いエラーを直す |
| **統合先で他チームのファイルを上書きしそう** | Importウィンドウに「Changed」が出ている。Importせず提出チームに確認 |
| **フォルダを移動したら参照が外れた** | エクスプローラーで移動した可能性。Unity上で移動し直す |
| **統合先でシーンが起動しない** | Build ProfilesのScene Listにシーンが追加されていない |
| **ReadMe.md が ReadMe.md.txt になった** | メモ帳の保存時に「ファイルの種類：すべてのファイル」を選び忘れ。名前を変更する |
| **ReadMe.md の日本語が文字化けする** | 保存時の文字コードがUTF-8になっていない。UTF-8で保存し直す |

   ポイントは4つだけです。

   - **1つのフォルダにまとめてから書き出す**

   - **空のプロジェクトで動作確認してから提出する**

   この4つを守れば、統合作業はとてもスムーズになります。良いゲームジャムを！
