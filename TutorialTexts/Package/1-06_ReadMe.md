# 【1-06】ReadMe.mdを書こう【1章：パッケージ編】

1. クリア条件：自分のミニゲームの説明書（ReadMe.md）が作れればOK！

2. パッケージができました。でも、ファイルだけ渡されても迷とら運営は困ります。
   「このゲームはどう操作するのか」「どのシーンから始まるのか」「何を追加したのか」が分からないからです。

3. そこで、**説明書のファイルを一緒に提出します**。名前は `ReadMe.md` に統一します。

   用語：ReadMe（リードミー）
   「最初に読んでね」という意味の、説明書ファイルの定番の名前。プログラムの世界では、フォルダの中にReadMeがあれば、まずそれを読むという習慣があります。

   用語：.md（マークダウン）
   文字だけで見出しや箇条書きを書けるファイル形式。`#` を付ければ見出し、`-` を付ければ箇条書きになります。**中身はただの文字なので、メモ帳でも作れます**。

4. まずは作り方から。メモ帳（Windows）またはテキストエディット（Mac）で作れます。

   【Windowsの場合】
   1. メモ帳を開く
   2. 後で出てくるテンプレートを貼り付けて、中身を書き換える
   3. `ファイル > 名前を付けて保存`
   4. **ファイルの種類を「すべてのファイル」に変更**
   5. **文字コードを「UTF-8」に変更**
   6. ファイル名を `ReadMe.md` にして保存

   ※手順4をやらないと `ReadMe.md.txt` という名前になってしまいます。
   ※手順5をやらないと、日本語が文字化けすることがあります。

   【Macの場合】
   テキストエディットは初期設定だとリッチテキストになるので、`フォーマット > 標準テキストにする` をしてから保存してください。

   ※VSCodeを使っている人は、新規ファイルを作って `ReadMe.md` の名前で保存するだけでOKです。

5. 置き場所は、**自分のミニゲームのフォルダの中**です。

   ```
   Assets/
     └ GameJam_2026_07_TeamA_MazeRunner/
         ├ ReadMe.md      ← ここに置く
         ├ Scenes/
         ├ Scripts/
         └ ...
   ```

   ここに置いてからパッケージを書き出せば、ReadMe.mdもパッケージに含まれます。
   ※すでに書き出し済みの人は、ReadMe.mdを置いてから**もう一度1-04の手順で書き出し直してください**。

6. では、中身を書きます。下のテンプレートを**そのままコピーして**使ってください。

   ```markdown
   # ゲームタイトル

   ## ゲーム概要
   （どんなゲームか2〜3行で。ジャンル、目的、勝敗条件など）

   ## 操作方法
   - 移動：
   - 決定：
   - その他：

   ## 最初に開くシーン
   （例：Title_TeamA.unity）

   ## 追加した機能（Package Manager）
   - （例：TextMeshPro）
   - 無ければ「なし」

   ## 追加したタグ
   - （例：Item）
   - 無ければ「なし」

   ## 追加したレイヤー
   - （例：Ground）
   - 無ければ「なし」

   ## その他
   - 想定プレイ時間：
   - 終了条件：（どうなったらゲームが終わるか）
   - 使用素材：（配布サイトの名前とURL。自作なら「自作」）
   - 既知の不具合：
   - 制作メンバー：
   - 連絡先：（DiscordのID。統合中に質問が出たとき用）
   ```

7. 書き方の例です。テンプレートを埋めるとこうなります。

   ```markdown
   # 迷路ダッシュ

   ## ゲーム概要
   制限時間内にゴールを目指す2D迷路ゲームです。
   道中のアイテムを取ると制限時間が5秒増えます。
   時間切れになるとゲームオーバーです。

   ## 操作方法
   - 移動：矢印キー
   - 決定：スペースキー
   - その他：Escキーでタイトルに戻る

   ## 最初に開くシーン
   Title_TeamA.unity

   ## 追加した機能（Package Manager）
   - TextMeshPro
   - Cinemachine

   ## 追加したタグ
   - Item
   - Goal

   ## 追加したレイヤー
   - なし

   ## その他
   - 想定プレイ時間：2分
   - 終了条件：ゴールに触れるとクリア、制限時間0でゲームオーバー。どちらもタイトルに戻ります
   - 使用素材：効果音ラボ（https://soundeffect-lab.info/）、キャラ絵は自作
   - 既知の不具合：まれに壁をすり抜けることがあります
   - 制作メンバー：○○、△△
   - 連絡先：Discord @maruo
   ```

8. 各項目について、迷とら運営が何に使うかを説明します。ここが分かると書きやすくなります。

   | 項目 | 運営がこう使う |
   |---|---|
   | ゲームタイトル | タイトル画面のメニューに表示する名前になる |
   | ゲーム概要 | 遊び方が分からないときに読む。紹介文にも使う |
   | 操作方法 | 動作確認するときに必要。遊ぶ人への案内にも使う |
   | 最初に開くシーン | タイトル画面から**このシーンへつなぐ**。これが無いと組み込めない |
   | 追加した機能 | 統合プロジェクトに同じ機能を入れる。無いとエラーで動かない |
   | 追加したタグ | 統合プロジェクトに同じタグを追加する。無いと実行時に止まる |
   | 追加したレイヤー | 同上。当たり判定が絡むので、抜けると挙動が変わる |
   | 終了条件 | ミニゲームが終わったらタイトルに戻す処理を入れるときに必要 |
   | 使用素材 | 配布サイトによっては表記が必要。まとめてクレジットに載せる |
   | 既知の不具合 | 統合後に発覚したとき「元からか、統合で壊れたか」の判断材料になる |
   | 連絡先 | 統合中に不明点が出たとき、すぐ聞ける |

9. 【書くときの注意】

   - **「なし」も書く**。空欄だと「書き忘れ」なのか「無い」のか分かりません
   - 追加したタグ・レイヤーは、**1-03で確認した内容**をそのまま書けばOK
   - シーン名は**拡張子（.unity）まで正確に**。`Title` と `title` の違いでも動きません

10. 書けたら、提出です。**パッケージファイルとReadMe.mdの両方**を提出してください。
    ReadMe.mdの中身は、Discordにそのまま貼り付けてもらえると運営が確認しやすいです。

11. ReadMe.mdが作れて、提出できたら、今回は完成です！
    ここまでで、書き出す側の作業は終わりです。次回は受け取る側（迷とら運営）の作業を見ていきます。
