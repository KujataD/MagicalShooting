# 【7】プレイ映像・サムネイル・タイトルロゴを用意する

1. .unitypackageとReadMe.mdのほかに、4つの素材を用意します。まとめるとこうなります。

   | 素材 | サイズ | 形式 |
   |---|---|---|
   | プレイ映像（短尺） | 1920×1080px | .mp4、15秒以内 |
   | プレイ映像（長尺） | 1920×1080px | .mp4、30秒〜1分 |
   | サムネイル画像 | 1920×1080px | .png |
   | タイトルロゴ透過素材 | 縦横1500px以内 | .png（背景透過） |

2. 【プレイ映像（短尺・15秒以内）】
   実際にゲームを操作しているところを、15秒以内で録画します。全チームの短尺映像をつなげて、ミニゲーム集全体の紹介動画を作るのに使います。イメージはこちらです。

   https://www.youtube.com/watch?v=mVWbUbeUGxA

   一番面白いところ・分かりやすいところだけを切り取ってください。タイトル画面からゆっくり始めると、15秒はあっという間に終わります。

3. 【プレイ映像（長尺・30秒〜1分）】
   短尺とは別に、実際に遊んでいる様子がひと通り分かる映像も用意します。タイトルからゲームオーバー（またはクリア）まで、一連の流れが伝わる長さにしてください。

   ※短尺・長尺のどちらも、画面サイズは1920×1080pxにそろえます。Unity上のGame画面が960×540などの場合は、画面録画ソフト側の出力設定を1920×1080に変更してください（ゲーム画面が小さいまま中央に映るのは問題ありません）。

4. 【サムネイル画像】
   ゲームの内容が一目で伝わる1枚を用意します。プレイ中のスクリーンショットでも、タイトル画面でも構いません。
   サイズは1920×1080px、形式は.pngです。

5. 【タイトルロゴ透過素材】
   ゲームタイトルのロゴだけを、背景を透明にした状態で書き出します。

   用語：透過（アルファチャンネル）
   画像の背景を「透明」として扱う仕組み。.pngはこれに対応しているので、背景を白や黒で塗りつぶさずに書き出せます。ミニゲーム集の共通レイアウトにロゴだけを重ねて表示するのに使います。

   縦・横どちらも**1500px以内**に収めてください。正方形である必要はなく、ロゴの形に合わせた縦長・横長で構いません。

6. 【ファイル名】
   4つの素材にも、.unitypackageと同じ名前を付けてから、内容が分かる言葉を後ろに足します。

   ```
   GameJam_2026_07_TeamA_MazeRunner_short.mp4     ← 短尺（15秒以内）
   GameJam_2026_07_TeamA_MazeRunner_long.mp4      ← 長尺（30秒〜1分）
   GameJam_2026_07_TeamA_MazeRunner_thumbnail.png ← サムネイル
   GameJam_2026_07_TeamA_MazeRunner_logo.png      ← タイトルロゴ
   ```

7. 用意ができたら、.unitypackageとあわせて5つを、【1】で案内したGoogle Driveのチームフォルダにアップロードします。
