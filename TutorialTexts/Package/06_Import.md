# 【6】迷とら運営：統合プロジェクトに読み込む

1. ここからは受け取る側、迷とら運営の作業です。
   提出する側も目を通しておくと、自分の提出物がどう扱われるかが分かります。

2. 全チームのパッケージがそろったら、統合プロジェクトを開きます。
   まだ無ければ、UnityHubで新規プロジェクトを作ります（テンプレートとバージョンは、チームで決めたものにそろえます）。

3. `Assets > Import Package > Custom Package...` を選びます。

   ![Import Packageメニュー](../package_images/1-06_import_menu.png)

4. ファイル選択の画面が出るので、1チーム分のパッケージを選びます。
   **必ず1つずつ読み込みます。** まとめて読み込むと、問題が起きたときにどのチームのものが原因か分からなくなります。

5. 「Import Unity Package」というウィンドウが開きます。中身の一覧が表示されるので、そのまま右下の「Import」を押します。

   ![Import Unity Packageウィンドウ](../package_images/1-06_import_dialog.png)

   - 上部にパッケージ名が表示されるので、どのチームのものか確認できます
   - 緑の「New」は新しく追加されるファイル、「Changed」は既にあるファイルが上書きされるという意味です

   「Changed」が出た場合は注意が必要です。他のチームのファイルを上書きしようとしている可能性があるため、Importを押さずに提出したチームへ確認します。

6. 読み込みが終わると、Projectウィンドウにファイルが追加されます。

   ![読み込み後のProjectウィンドウ](../package_images/1-06_after_import.png)

   各チームがフォルダをまとめているので、チームごとに分かれた状態になります。

   ![チームごとに分かれた状態](../package_images/1-02_project_structure.png)

7. 読み込んだら、まずそのチームのReadMe.mdを開きます。

   - 追加した機能 → 統合プロジェクトにも同じものを入れる
   - 追加したタグ・レイヤー → `Edit > Project Settings > Tags and Layers` で追加する
   - 最初に開くシーン → タイトル画面からつなぐ先として控える
   - プレイ制限時間 → ミニゲームの制限時間として設定する

   これを先にやっておくと、次のエラー確認がスムーズになります。

8. 次にConsoleを確認します。赤いエラーが出ていたら、そのチームのミニゲームはまだ動きません。

   ![読み込み後に出たエラー](../package_images/1-06_console_errors.png)

   実際に試したところ、3つのエラーが出ました。内容はこれです。

   ![エラーの詳細](../package_images/1-06_error_detail.png)

   ```
   error CS0234: The type or namespace name 'VisualScripting'
   does not exist in the namespace 'Unity'
   ```

   「スクリプトが使っている機能が、このプロジェクトに入っていない」という意味です。パッケージに入らないものが原因です。

9. 対処は2つあります。

   - `Window > Package Management > Package Manager` から、エラーに出ている機能を追加する
   - その機能を実際には使っていない場合、スクリプトの `using` の行を消す（提出したチームに確認してから）

10. コンパイルエラーが残った状態でUnityを開き直すと、この画面が出ます。

    ![Enter Safe Mode?ダイアログ](../package_images/1-06_safemode_dialog.png)

    - **Enter Safe Mode**：エラーを直すことに集中できるモードで開く
    - **Ignore**：とりあえず無視して開く（エラーは残ったまま）

    どちらを選んでも、エラーを直さない限りゲームは動きません。エラーは読み込んだその日に直します。

11. 全チーム分は、この順番で進めます。

    ```
    1チーム読み込む → ReadMe.mdの内容を反映 → エラーを確認 → 直す → 動作確認 → 次のチームを読み込む
    ```

    まとめて読み込むと、エラーが混ざって原因が分からなくなります。

12. 最後に、各ミニゲームのシーンをBuild Settingsに登録します。
    読み込んだだけではビルドに含まれないため、`File > Build Profiles` を開いて、Scene Listに全ミニゲームのシーンを追加します。
    ここでReadMe.mdの「最初に開くシーン」を使います。
