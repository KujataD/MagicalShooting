## 【A】提出までの流れ

```
① Unityで自分のミニゲーム用フォルダを1つ作る
   名前：GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
        ↓
② そのフォルダの中に、自分の素材・スクリプト・シーンを全部移動
   （移動はUnityのProjectウィンドウ上で！）
        ↓
③ Unityで再生して、まだ動くか確認
        ↓
④ 追加した機能・タグ・レイヤーをメモ（1-03）
        ↓
⑤ フォルダを右クリック →「Export As Asset Package...」
        ↓
⑥ Include dependencies にチェックが入っているか確認 → Export
        ↓
⑦ ファイル名を決められた形式で保存
        ↓
⑧ 空のプロジェクトを作って読み込み、動作確認（1-05）
        ↓
⑨ パッケージ＋メモを提出
```

## 【B】ファイル名とフォルダ名のルール

```
GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
```

| 良い例 ⭕ | 避けたい例 ✕ |
|---|---|
| GameJam_2026_07_TeamAlpha_MazeRunner | game.unitypackage |
| GameJam_2026_07_TeamBravo_ShootingStar | 最新版.unitypackage |
| GameJam_2026_07_TeamCharlie_RhythmCat | GameJam 2026 07 チームC.unitypackage |

- `<>` は書かない（`Team` の後にそのままチーム名）
- **半角英数とアンダースコア（_）だけ**を使う
- 日本語・スペース・記号は使わない
- **フォルダ名もファイル名と同じ**にする

## 【C】パッケージに入るもの・入らないもの

| 種類 | 入る？ | 対応 |
|---|---|---|
| 画像・音・スクリプト・シーン・プレハブ | ⭕ | 自分のフォルダにまとめる |
| Package Managerで追加した機能 | ✕ | 提出時に申告する |
| タグ・レイヤー | ✕ | 提出時に申告する |
| 入力設定（Input） | ✕ | 提出時に申告する |
| Build Settingsのシーン一覧 | ✕ | 「最初に開くシーン」を申告する |

## 【F】困ったとき逆引き表

| こうなった | こうする |
|---|---|
| **書き出したファイルが数KBしかない** | フォルダを選ばずに書き出した可能性。自分のフォルダを右クリックしてやり直す |
| **読み込んだら絵が白い四角になる** | Include dependencies のチェック漏れ。チェックを入れて書き出し直す |
| **`型または名前空間が見つかりません` エラー** | 統合先に無い機能を使っている。使っていないなら該当の `using` を消す。使っているなら申告する |
| **`Tag: ○○ is not defined` エラー** | 自分で追加したタグを使っている。統合先に同じタグを追加してもらう |
| **Unityを開いたら Enter Safe Mode? が出た** | コンパイルエラーが残っている。Ignoreで開いて、Consoleの赤いエラーを直す |
| **統合先で他チームのファイルを上書きしそう** | Importウィンドウに「Changed」が出ている。Importせず提出者に確認 |
| **フォルダを移動したら参照が外れた** | エクスプローラーで移動した可能性。Unity上で移動し直す |
| **統合先でシーンが起動しない** | Build ProfilesのScene Listにシーンが追加されていない |
