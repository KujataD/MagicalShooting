# 【1-01】ミニゲームを1つに集めよう【1章：パッケージ編】

1. クリア条件：何を作るのか、そのために何を提出するのかが分かればOK！

2. ここからは別巻、Unity Packageの使い方です。
   作るのは、**各チームが作ったミニゲームを1つにまとめたゲーム**です。タイトル画面から好きなミニゲームを選んで遊べる、ミニゲーム集の形になります。

3. ここで問題があります。ミニゲームは**チームごとに別々のUnityプロジェクト**で作られています。

   ```
   チームAのプロジェクト　←　迷路ゲーム
   チームBのプロジェクト　←　シューティング
   チームCのプロジェクト　←　リズムゲーム
   チームDのプロジェクト　←　パズルゲーム
   ```

   これを最終的に、1つのプロジェクトの中に全部入れる必要があります。

   ```
   統合プロジェクト
     ├ 迷路ゲーム
     ├ シューティング
     ├ リズムゲーム
     └ パズルゲーム
   ```

4. 「プロジェクトのフォルダごと渡せばいいのでは？」と思うかもしれませんが、それだと**プロジェクトが4つ並ぶだけ**で、1つのゲームにはなりません。
   必要なのは「プロジェクトそのもの」ではなく、「**そのミニゲームを動かすのに必要なファイル一式**」を取り出して渡すことです。

5. そのための仕組みが、Unityに用意されている Unity Package です。

   用語：Unity Package（.unitypackage）
   Unityのプロジェクトから、**指定したファイルをまとめて1つのファイルに書き出したもの**。受け取った側は、それを自分のプロジェクトに読み込むと、フォルダ構成そのままでファイルが追加されます。

6. 作業の流れはこうなります。

   ```
   ① 各チーム：自分のミニゲームを .unitypackage に書き出す
                    ↓
   ② 各チーム：ファイルとReadMe.mdを提出する
                    ↓
   ③ 迷とら運営：全部を統合プロジェクトに読み込む
                    ↓
   ④ 迷とら運営：タイトル画面から各ミニゲームへつなぐ
   ```

   この別巻では、**①〜②の提出まで**（1-02〜1-06）と、**③の読み込み**（1-07）を扱います。

7. 【最重要】提出するファイルの名前は、全チーム統一します。

   ```
   GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
   ```

   チーム名はA〜Dなので、こうなります。

   ```
   GameJam_2026_07_TeamA_MazeRunner.unitypackage
   GameJam_2026_07_TeamB_ShootingStar.unitypackage
   GameJam_2026_07_TeamC_RhythmCat.unitypackage
   GameJam_2026_07_TeamD_PuzzleBox.unitypackage
   ```

   ※`<>` は書きません。`Team` の後にそのままチーム名（A〜D）をつなげます。
   ※半角英数とアンダースコア（_）だけを使ってください。日本語やスペースが入ると、読み込む側で不具合の原因になります。

8. なぜ名前を統一するのか。迷とら運営の画面には、全チームのファイルが並びます。

   ```
   ⭕ 統一されている場合
      GameJam_2026_07_TeamA_MazeRunner.unitypackage
      GameJam_2026_07_TeamB_ShootingStar.unitypackage
      GameJam_2026_07_TeamC_RhythmCat.unitypackage
      GameJam_2026_07_TeamD_PuzzleBox.unitypackage
      → どれが誰のもので、いつの提出物か一目で分かる

   ✕ バラバラの場合
      game.unitypackage
      最新版.unitypackage
      test2.unitypackage
      → 中身を開くまで分からない。同名ファイルで上書き事故も起きる
   ```

9. 目的（ミニゲームを1つに集める）と、提出するもの（決まった名前の.unitypackage）が分かったら、今回は完成です！
   次回は、書き出す前の準備をします。
