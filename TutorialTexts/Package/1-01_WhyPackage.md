# 【1-01】ミニゲームを1つに集めよう【1章：パッケージ編】

1. クリア条件：今回何を作るのか、そのために何を提出するのかが分かればOK！

2. ここからは別巻、Unity Packageの使い方です。
   今回のゲームジャムでは、**各チームが作ったミニゲームを1つのゲームにまとめます**。タイトル画面から好きなミニゲームを選んで遊べる、いわゆるミニゲーム集です。

3. でも、ここで問題があります。ミニゲームは**チームごとに別々のUnityプロジェクト**で作られています。

   ```
   Aチームのプロジェクト   ← 迷路ゲーム
   Bチームのプロジェクト   ← シューティング
   Cチームのプロジェクト   ← リズムゲーム
   ```

   これを最終的に、1つのプロジェクトの中に全部入れる必要があります。

   ```
   統合プロジェクト
     ├ 迷路ゲーム
     ├ シューティング
     └ リズムゲーム
   ```

4. 「プロジェクトのフォルダごと渡せばいいのでは？」と思うかもしれませんが、それだと**プロジェクトが3つ並ぶだけ**で、1つのゲームにはなりません。
   必要なのは「プロジェクトそのもの」ではなく、「**そのミニゲームを動かすのに必要なファイル一式**」を取り出して渡すことです。

5. そのための仕組みが、Unityに用意されている Unity Package です。

   用語：Unity Package（.unitypackage）
   Unityのプロジェクトから、**指定したファイルをまとめて1つのファイルに書き出したもの**。受け取った側は、それを自分のプロジェクトに読み込むと、フォルダ構成そのままでファイルが追加されます。

6. 今回のゲームジャムでの流れは、こうなります。

   ```
   ① 各チーム：自分のミニゲームを .unitypackage に書き出す
                    ↓
   ② 各チーム：できたファイルを提出する（Discordなど）
                    ↓
   ③ 統合担当：全部を統合プロジェクトに読み込む
                    ↓
   ④ 統合担当：タイトル画面から各ミニゲームへつなぐ
   ```

   この別巻では、**①の書き出し**（1-02〜1-05）と、**③の読み込み**（1-06）を扱います。

7. 【最重要】提出するファイルの名前は、全チーム統一します。

   ```
   GameJam_2026_07_Team<チーム名>_<ゲームタイトル>
   ```

   例：

   ```
   GameJam_2026_07_TeamAlpha_MazeRunner.unitypackage
   GameJam_2026_07_TeamBravo_ShootingStar.unitypackage
   GameJam_2026_07_TeamCharlie_RhythmCat.unitypackage
   ```

   ※`<>` は書きません。`Team` の後にそのままチーム名をつなげます。
   ※半角英数とアンダースコア（_）だけを使ってください。日本語やスペースが入ると、読み込む側で不具合の原因になります。

8. なぜ名前を統一するのか。統合担当の画面には、全チームのファイルが並びます。

   ```
   ⭕ 統一されている場合
      GameJam_2026_07_TeamAlpha_MazeRunner.unitypackage
      GameJam_2026_07_TeamBravo_ShootingStar.unitypackage
      GameJam_2026_07_TeamCharlie_RhythmCat.unitypackage
      → どれが誰のもので、いつの提出物か一目で分かる

   ✕ バラバラの場合
      game.unitypackage
      最新版.unitypackage
      test2.unitypackage
      → 中身を開くまで分からない。同名ファイルで上書き事故も起きる
   ```

9. 今回の目的（ミニゲームを1つに集める）と、提出するもの（決まった名前の.unitypackage）が分かったら、今回は完成です！
   次回は、書き出す前の準備をします。
