# 【7】通し：投稿チェックリスト【保存版】

1. 最後に、ここまでの内容を忘れても投稿できるようにまとめます。

---

## 【A】投稿までの流れ

```
① Project Settings で以下を設定する
   Compression Format：Gzip
   Decompression Fallback：チェックを外す
   Default Canvas Width / Height：960 / 540
        ↓
② File > Build Profiles でWeb向けにビルドする
        ↓
③ unityroomで「ゲームを登録」→ タイトル・紹介文を入力
        ↓
④ 「Webビルドアップロード」で Build フォルダをアップロード
        ↓
⑤ 「公開設定」で「限定公開」を選んで更新
        ↓
⑥ ゲームのURLをプレイ会のDiscordチャンネルなどに共有
```

---

## 【B】ビルド前に確認する2つの設定

| 設定 | 場所 | 正しい値 |
|---|---|---|
| Compression Format | Project Settings > Player > Publishing Settings | Gzip |
| Decompression Fallback | 同上 | チェックを外す |

この2つを間違えると、アップロードできても正しく動きません。ビルドをやり直せば直ります。

---

## 【C】公開設定の使い分け

| 設定 | 用途 |
|---|---|
| 非公開 | 作業中、まだ誰にも見せない段階 |
| **限定公開** | **プレイ会など、URLを知っている身内だけに見せる段階** |
| 一般公開 | 完成後、誰でも遊べるように公開する段階 |

限定公開には、一般公開で必要なアイコン画像や実況ポリシーの設定は不要です。

---

## 【D】困ったとき逆引き表

| こうなった | こうする |
|---|---|
| **アップロード後、ゲームが読み込み中のまま止まる** | Compression FormatがGzipになっていない。設定してビルドし直す |
| **ファイルの拡張子が `.unityweb` になっている** | Decompression Fallbackのチェックが外れていない。外してビルドし直す |
| **ゲーム画面が窮屈、または余白だらけ** | Default Canvas Width / Height が960×540になっていない |
| **アップロードしてもファイルが「未完了」のまま** | 通信が不安定な可能性。もう一度アップロードし直す |
| **限定公開にしたのにURLを知らない人が来た** | URLをオープンな場所に貼っていないか確認する |
| **どのビルドが最新か分からなくなった** | アップロード画面の「更新日時」でファイルごとの時刻を確認する |
