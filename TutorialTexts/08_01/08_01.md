# 【8-01】スコアを表示しよう【8章：UI】

クリア条件：敵を倒すたびに画面左上のスコアが加算されて表示される状態にする

1. `GameManager`が数えている撃破数（`defeatCount_`）を、スコアとして画面に表示します。

2. `GameManager.cs`に、外部から撃破数を読み取るためのメソッドを追加します。

   ```csharp
   /// <summary>
   /// 現在の撃破数を取得（スコア表示用）
   /// </summary>
   public int GetDefeatCount()
   {
       return defeatCount_;
   }

   /// <summary>
   /// クリアに必要な撃破数を取得（スコア表示用）
   /// </summary>
   public int GetClearTargetCount()
   {
       return clearTargetCount_;
   }
   ```

   `defeatCount_`と`clearTargetCount_`はどちらも`private`のままなので、直接書き換えられることはありません。読み取り専用のメソッド越しに値を渡します。`GetClearTargetCount()`はこの章では使いません。

3. `Assets/Scripts/UI`フォルダを新しく作り、`ScoreDisplay.cs`という名前で次のスクリプトを作ります。

   ```csharp
   using TMPro;
   using UnityEngine;

   public class ScoreDisplay : MonoBehaviour
   {
       // 撃破数を表示するテキスト
       [SerializeField] private TextMeshProUGUI scoreText_;

       // Update is called once per frame
       void Update()
       {
           // 現在の撃破数を表示する
           int defeatCount = GameManager.Instance.GetDefeatCount();
           scoreText_.text = "SCORE " + defeatCount;
       }
   }
   ```

   `GameManager.Instance`はシングルトンなので、どこからでも呼び出せます。

4. Hierarchyを右クリックして`UI > Canvas`を作成してください（`GameScene`にはまだCanvasがありません。`EventSystem`も一緒に作られます）。Canvasの子に`UI > Text - TextMeshPro`を作成し、名前を`ScoreText`にします。

5. `ScoreText`のRect Transformを設定してください。`Anchors`（Min・Max・Pivot）をすべて`X: 0, Y: 1`（画面の左上）にし、`Pos X: 20, Pos Y: -20`にします。Textの内容は`SCORE 0`にします。

   四隅にアンカーを固定すると、`Pos X`・`Pos Y`が「左上の角からの距離」になり、解像度やアスペクト比が変わっても位置がずれにくくなります。

6. `ScoreText`に`ScoreDisplay`をAdd Componentし、`Score Text_`に`ScoreText`自身を設定してください。

   ![ScoreDisplayコンポーネントを追加](score_display_component.png)

   ![Score Text_にScoreTextを設定](score_text_wired.png)

7. Playを押して敵を倒し、スコアが`SCORE 0`→`SCORE 1`…と増えればクリアです。
