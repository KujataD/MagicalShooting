# 【1-06】リポジトリを作ろう【1章：Git導入編】

1. クリア条件：GitHubにチーム用のリポジトリを作って、メンバーを招待できればOK！

2. いよいよプロジェクト用の置き場をGitHubに作ります。この置き場をリポジトリと呼びます。

   用語：リポジトリ（repository）
   プロジェクト1つ分のファイルと、**その全変更履歴**が入っている置き場。プロジェクト1つにつきリポジトリ1つ、と考えてください。

3. ※この作業は**チームで1人（代表の人）だけ**がやればOKです。他のメンバーは眺めるだけで大丈夫。自分が代表でない人は、次回の「クローン」から参加になります。

4. GitHubにログインした状態で、右上の「＋」→「New repository」を選びましょう。

5. 設定項目を埋めていきます。

   - **Repository name**：プロジェクト名（例：MagicalShooting）。半角英数とハイフン推奨
   - **Description**：どんなゲームか一言（任意）
   - **Public / Private**：
     - Public＝インターネット上の誰でも見られる
     - Private＝招待した人だけ見られる
     練習ならどちらでもOK。素材の権利が気になるならPrivateが安全です

6. 下にスクロールして、ここが**今回いちばん大事なところ**です。

   - **Add a README file**：チェックを入れる（プロジェクトの説明書。あとで書けます）
   - **Add .gitignore**：ドロップダウンから **Unity** を選ぶ ← 前回説明したものです
   - **Choose a license**：チーム内制作なら「None」でOK

   .gitignoreで「Unity」を選び忘れると、Libraryフォルダまで全部共有されてしまい、前回説明した問題がそのまま起きます。ここだけは必ず確認してください。

7. 「Create repository」を押すと、リポジトリが作成されます！

   ![作成されたリポジトリ](../git_images/1-06_repo_top.png)

   ※このスクショは、すでに中身が入った状態のものです。作りたてはREADME.mdと.gitignoreだけが入っています。

8. 次に、チームメンバーを招待します。これをやらないと、メンバーは中身を見られても**データを送れません（プッシュできません）**。

   - リポジトリの上部メニューから「Settings」を開く
   - 左メニューの「Collaborators」（共同編集者）を選ぶ
   - 「Add people」を押して、メンバーのGitHub IDを入力

   1-02でメンバーに「IDを教えてね」と伝えておいたのは、このためでした。

9. 招待されたメンバーには、GitHubからメールが届きます。中の「Accept invitation」を押してもらえば参加完了です。
   ※招待は7日で期限切れになるので、メンバーには「招待を送ったので確認してね」と一声かけましょう。

10. 最後に、**リポジトリのURLをチーム全員に共有**しましょう。次回、全員がこのURLを使います。

    ```
    https://github.com/ユーザー名/リポジトリ名
    ```

11. リポジトリができて、メンバーが参加できたら、今回は完成です！
    次回は、このリポジトリの中身を自分のPCに持ってきます。
