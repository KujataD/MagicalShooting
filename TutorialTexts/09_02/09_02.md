# 【9-02】発射音を鳴らそう【9章：サウンド】

1. クリア条件：魔法弾を発射した瞬間に発射音が鳴る状態にする

2. [効果音ラボ](https://soundeffect-lab.info/)の「戦闘」カテゴリから「魔法のステッキ」をダウンロードし、`Assets/Sounds/SE`に`shoot.mp3`という名前で保存します。

3. `PlayerFire.cs`に、発射音のフィールドと処理を追加します。

   ```csharp
   public class PlayerFire : MonoBehaviour
   {
       // 魔法弾のプレハブ
       [SerializeField] private GameObject bulletPrefab_;

       // 発射音を鳴らすAudioSource
       [SerializeField] private AudioSource audioSource_;

       // 発射音
       [SerializeField] private AudioClip shootSe_;

       // Start is called once before the first execution of Update after the MonoBehaviour is created
       void Start()
       {
           
       }

       // Update is called once per frame
       void Update()
       {
           // スペースキーで魔法弾発射
           if (Input.GetKeyDown(KeyCode.Space))
           {
               // 生成する(弾のプレハブを, プレイヤーの座標で, 何も回転していない状態で) 
               Instantiate(bulletPrefab_, transform.position, quaternion.identity);

               // 発射音を鳴らす
               audioSource_.PlayOneShot(shootSe_);
           }
       }
   }
   ```

   `PlayOneShot`は、再生中でも指定した音を重ねて鳴らすメソッドです。連射しても音が途切れません。

4. `GameScene`の`Player`に`Audio Source`をAdd Componentしてください。

   ![Playerに追加したAudio Source](player_audiosource_added.png)

5. `Player Fire`の`Audio Source_`に`Player`自身の`Audio Source`を、`Shoot Se_`に`shoot`を設定してください。

   ![Shoot Se_にshootを設定](shoot_se_wired.png)

6. Playを押し、Spaceキーで弾を発射するたびに音が鳴ればクリアです（連射しても途切れません）。
