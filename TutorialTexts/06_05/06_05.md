# 【6-05】建物を3レイヤーに分けて奥行きを出そう【6章：アニメーション・背景】

1. クリア条件：建物が奥・中間・手前の3段階の大きさで流れ、地面に接している状態にする

2. 建物を奥・中間・手前の3レイヤーに分けます。奥ほど小さく・遅く、手前ほど大きく・速く流します。9種類の建物の絵（`Assets/Images/Background`）はどのレイヤーでも同じで、違うのは大きさと速さだけです。6-04の`ScrollingLayerSpawner`の設定をレイヤーごとに変えます。

3. `Create Empty`から空のオブジェクト`BackgroundFar`を作成し、`ScrollingLayerSpawner`をAdd Componentしてください。

4. `BackgroundFar`の`ScrollingLayerSpawner`を次のように設定してください。

- Sprites：`Assets/Images/Background`の9枚（`background1`〜`background9`）
- Sorting Layer Name：`Background`
- Align To Ground Y：チェックあり
- Scale：`0.5`
- Min Spacing：`2.5`
- Distance：`10`

   ![BackgroundFarの設定](background_far_inspector.png)

   `Distance`が最大の`10`なので、Fogが最大までかかります。

5. `BackgroundFar`をCtrl+Dで複製し、`BackgroundMid`にして次のように変更してください。

- Order In Layer：`2`
- Scale：`0.6`
- Speed：`3`
- Min Spacing：`3.5`
- Distance：`5`

   ![BackgroundMidの設定](background_mid_inspector.png)

   `Distance`が中間の`5`なので、Fogは半分だけかかります。

6. もう一度複製して`BackgroundNear`にし、次のように変更してください。

- Order In Layer：`4`
- Scale：`0.7`
- Speed：`4.5`
- Min Spacing：`4.5`
- Distance：`0`

   ![BackgroundNearの設定](background_near_inspector.png)

   `Distance`が`0`なので、Fogはかかりません。

   Order In Layerを0・2・4と分けているのは、同じ`Background`レイヤーの中で、手前のものが奥のものを隠すように描画順を揃えるためです（数字が大きいほど手前）。1つおきにしているのは、6-04の霧の板が建物の1つ上（Order In Layer＋1）に描かれるためで、隣のレイヤーの建物と番号が重ならないようにしています。

7. Hierarchyは次のようになります。

   ![完成したHierarchyの並び](hierarchy_final.png)

8. Playを押し、3つの建物がそれぞれ違う速さで流れ、すべて地面に接していればクリアです。

   ![Play中の完成イメージ](final_result.png)

9. これで6章は完成です。
