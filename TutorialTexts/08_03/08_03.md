# 【8-03】タイトル画面にボタンを追加しよう【8章：UI】

1. クリア条件：タイトル画面の「START」ボタンをクリックしてもSpaceキーを押してもゲームが始まる状態にする

2. ここまでのタイトル画面・ゲームオーバー画面・ゲームクリア画面は、どれも`SceneChangeOnKey`というスクリプトでキー入力だけを見てシーンを切り替えていました。ここからは、クリックとキー入力の両方に反応するボタンに置き換えていきます。

3. `Assets/Scripts/UI`に`SceneLoader.cs`という名前で次のスクリプトを作ります。ボタンの`On Click`から呼び出すための、シーン読み込み専用のスクリプトです。

   ```csharp
   using UnityEngine;
   using UnityEngine.SceneManagement;

   public class SceneLoader : MonoBehaviour
   {
       /// <summary>
       /// 指定した名前のシーンを読み込む（ボタンのOnClickから呼び出す）
       /// </summary>
       public void LoadScene(string sceneName)
       {
           SceneManager.LoadScene(sceneName);
       }
   }
   ```

4. 続けて`KeyableButton.cs`という名前で次のスクリプトを作ります。指定したキーが押されたときに、ボタンをクリックしたときと同じ処理を呼び出すためのスクリプトです。

   ```csharp
   using UnityEngine;
   using UnityEngine.UI;

   // クリックだけでなく、指定したキーでも同じボタンを押せるようにする
   [RequireComponent(typeof(Button))]
   public class KeyableButton : MonoBehaviour
   {
       // ボタンのクリックと同時に反応させたいキー
       [SerializeField] private KeyCode key_ = KeyCode.Space;

       // 対象のボタン
       private Button button_;

       void Start()
       {
           button_ = GetComponent<Button>();
       }

       // Update is called once per frame
       void Update()
       {
           // キーが押されたら、ボタンをクリックしたときと同じ処理を呼び出す
           if (Input.GetKeyDown(key_))
           {
               button_.onClick.Invoke();
           }
       }
   }
   ```

5. `TitleScene`を開き、Canvasの子として「UI > Button - TextMeshPro」でボタンを作り、名前を`StartButton`にします。「Press Space to Start」の下あたりに配置し、ラベルのテキストを`START`にします。

   ![StartButtonを配置](start_button_positioned.png)

   ラベルのテキストは、既定のフォント（LiberationSans SDF）が日本語のグリフを持っていないため、英語表記にしています。

   ![ラベルをSTARTに変更](start_button_text.png)

6. `StartButton`に`SceneLoader`と`KeyableButton`を追加します。`KeyableButton`の`Key_`は既定の`Space`のままにしておきます。

7. `StartButton`の`Button`コンポーネントにある`On Click()`に「＋」で項目を追加し、対象に`StartButton`自身を設定します。関数は`SceneLoader.LoadScene(string)`を選び、引数に`GameScene`と入力します。

   ![OnClickにSceneLoader.LoadSceneを設定](start_button_onclick.png)

   これで、ボタンをクリックしても`KeyableButton`がSpaceキーを検知してボタンをクリックしたことにしても、同じ`LoadScene("GameScene")`が呼ばれるようになりました。

8. 役目が重複した`SceneChanger`（`SceneChangeOnKey`が付いたオブジェクト）はもう不要なので、Hierarchyから削除します。

   ![SceneChangerを削除した状態](scenechanger_removed.png)

9. Playを押し、`START`ボタンをクリックしてゲームが始まることと、タイトル画面に戻ってSpaceキーでも始まることの両方を確認します。

   ![STARTボタンでゲームが始まった状態](title_play_confirm.png)
