# Magical Shooting

魔女っ子が魔法弾で敵を撃ちまくる2Dシューティングゲームです。

## 遊び方

- 矢印キー：移動
- スペースキー：魔法弾を発射
- 敵を20体倒したらゲームクリア！敵にぶつかったらゲームオーバー！

## 開発環境

- Unity 6.3 LTS (6000.3.15f1)
- Universal 2D (URP)
